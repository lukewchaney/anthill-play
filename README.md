# Anthill (web build)

**Play: https://lukewchaney.github.io/anthill-play/**

This repository only holds the compiled browser version of Anthill (single player), served by GitHub Pages. The source code is kept elsewhere.

- Works best in desktop Chrome, Edge or Firefox with a mouse and keyboard.
- Saves are kept in your browser's local storage (on that device and browser only).
- Multiplayer needs the desktop version.

Music and sound effects: Powered by Stability AI (Stable Audio Open). Made with KNI.
